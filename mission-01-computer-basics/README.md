# Mission 1 — Know your computer

## 1. Task / objective

Trace an everyday task through IPOS and identify hardware, software and everyday computer systems.

## 2. Work completed

### Task 1.1 — Typing and saving a document

| Stage | What happens | Hardware or component |
| --- | --- | --- |
| Input | I type a sentence and choose Save. | Keyboard and trackpad |
| Processing | The editor handles the keystrokes, updates the document in memory and prepares its file contents when saving. | CPU, RAM and editor |
| Output | The typed sentence appears on screen. | Display |
| Storage | The editor writes the document to a file I can reopen later. | SSD and filesystem |

Keypresses become text the editor can display. Saving writes the text to the SSD so it persists after the editor closes.

### Task 1.2 — Hardware and software

| Item | Hardware or software | Software type | Purpose |
| --- | --- | --- | --- |
| Keyboard | Hardware | Not applicable | Enters text and shortcuts. |
| Trackpad | Hardware | Not applicable | Moves the pointer and selects items. |

### Task 1.3 — Systems around us

| System | Main purpose | One input | One output |
| --- | --- | --- | --- |
